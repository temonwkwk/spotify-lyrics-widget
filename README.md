# Spotify Lyrics Widget

Prototipe widget desktop floating (Electron) untuk menampilkan lirik lagu Spotify.

## Jalankan

```bash
npm install
npm start
```

Widget UI sudah berjalan. Integrasi Spotify membutuhkan Spotify Client ID + OAuth (`user-read-playback-state`), lalu sumber lirik eksternal seperti LRCLIB. Tombol Connect saat ini menandai titik integrasi tersebut dan tidak mengarang koneksi tanpa kredensial.
